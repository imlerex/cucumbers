# 🥒 ЦАРЬ-ОГУРЕЦ · Deluxe Artisanal Pickle Store

> Премиальный интернет-магазин маринованных огурцов с интерактивным 3D-огурцом, эффектом воды и брызг на экране, корзиной заказов и поддержкой локального Go-сервера и GitHub Pages.

---

## ✨ Что реализовано в проекте

1. **Большой 3D-Огурец (WebGL Raymarching Engine)**:
   - Создан на чистом WebGL без тяжелых сторонних библиотек: мгновенная загрузка 0 мс!
   - Реалистичная анатомия огурца: изогнутая форма, продольные ребра, хрустящие пупырышки (бугорки) с золотисто-лаймовыми кончиками, натуральный стебель и влажный глянец рассола (clearcoat specular).
   - **Интерактивное вращение при скролле**: огурец плавно крутится вокруг своей оси при прокрутке страницы.
   - **Информационный текст СЗАДИ огурца**: огромная типографика (`Х Р У С Т`, `Р А С С О Л`, `С Т Е К Л О`, `К Р А Ф Т`) расположена физически **позади** вращающегося 3D-огурца (`z-index: 1`, огурец `z-index: 2`), создавая потрясающий 3D-эффект глубины и объема!
   - **Управление мышью и касанием**: огурец можно свободно хватать и крутить пальцем или мышью на 360° с плавной инерцией.
   - Кнопка **«Встряхнуть огурец»** и иконки на карточках товаров для мгновенной раскрутки.

2. **Водный вайб на экране (Water & Brine System)**:
   - **Интерактивные круги на воде (Water Ripples)**: при движении курсора или клике по экрану расходятся реалистичные водные круги.
   - **Поднимающиеся пузырьки рассола (Fermentation Bubbles)**: мелкие пузырьки с естественным покачиванием поднимаются со дна банки; при быстром скролле или кликах появляется дополнительный гейзер пузырьков.
   - **Капли и конденсат на стекле (Chilled Glass Droplets)**: капли запотевшего холодного стекла по краям экрана создают ощущение взгляда сквозь ледяную банку из погреба.
   - **Синтезатор звуков (Web Audio API)**:
     - Настоящий сочный хруст огурца (`playCrunch()`) при добавлении в корзину и кликах.
     - Освежающий всплеск капли воды (`playSplash()`).
     - Работает прямо в браузере без внешних аудиофайлов.
   - Кнопки управления в шапке: переключатель звука (`🔇 / 🔊`) и переключатель водного вайба (`💧 / 🫧`).

3. **Полноценный магазин и корзина**:
   - 8 фирменных сортов огурцов с фильтрацией по категориям (Хиты, Острые, Новинки, Премиум, Наборы).
   - Выдвижная шторка корзины с подсчетом количества, суммы и интерактивной шкалой бесплатной доставки.
   - Модальное окно оформления заказа.
   - Отправка готового заказа прямо в **Telegram** с автозаполнением всех деталей и кнопка **копирования текста заказа** в буфер обмена.
   - Сохранение корзины в `localStorage`.

4. **Сервер на Go (`main.go`)**:
   - Написан на стандартной библиотеке Go (`net/http`) — никаких сторонних `go get` зависимостей.
   - Раздает статические файлы сайта на порту `:8080`.
   - API эндпоинт `POST /api/order`: принимает заказы с сайта и сохраняет их в `orders.json`.
   - API эндпоинт `GET /api/health`: проверка здоровья и аптайма сервера.
   - Красивый баннер в терминале при запуске и graceful shutdown (`Ctrl+C`).

## 🚀 Как запустить локально с помощью Go

Если у вас установлен Go:

```bash
# Запустить сервер
go run main.go

# Или указать свой порт:
go run main.go -port 3000
```

После этого откройте в браузере:  
👉 **[http://localhost:8080](http://localhost:8080)**

## 🌐 Как выложить на GitHub Pages за 2 минуты

Сайт полностью оптимизирован для **GitHub Pages** (все пути относительные, корень содержит `index.html`):

1. Создайте новый репозиторий на GitHub (например, `cucumber-store`).
2. Загрузите все файлы из этой папки в репозиторий:
   ```bash
   git init
   git add .
   git commit -m "Initial Tsar Cucumber release 🥒"
   git branch -M main
   git remote add origin https://github.com/ВАШ_НИК/cucumber-store.git
   git push -u origin main
   ```
3. В настройках репозитория на GitHub:
   - Перейдите в **Settings** → **Pages**.
   - В разделе **Branch** выберите `main` и папку `/(root)`.
   - Нажмите **Save**.
4. Через 30 секунд сайт станет доступен вам и вашим друзьям по ссылке:  
   👉 `https://ВАШ_НИК.github.io/cucumber-store/`
